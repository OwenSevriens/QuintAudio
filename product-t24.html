Description

Built so a single T24 sits inside any Quint system without re-tuning.

The T24 carries the T-Series target tuning into a 2×12″ / 4″ / 2.5″ three-way point source. A pair of 12″ low-frequency drivers flank a 4″ mid and 2.5″ high-frequency motor, all firing through a 70° × 40° horn.

A two-channel Class-D amp delivers FIR-corrected DSP with AES75 protection that limits long-term excursion without choking transients. The cabinet is birch ply with a PU coat.

Rigging points and side handles match the FB-T24 fly-bar; a pole socket and YK-T24 yoke cover the install side. One enclosure, every venue.
